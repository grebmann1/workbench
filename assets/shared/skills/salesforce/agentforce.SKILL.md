# Agentforce

Inspect and manage Agentforce agents in the connected Salesforce org.

## When to use
- User asks about their Agentforce agents
- User wants to see agent configuration, topics, or actions
- User wants to understand agent dependencies
- User asks to list or describe AI agents in the org

## Tools

| Tool | Purpose |
|------|---------|
| agentforce_list_agents | List all Agentforce agents in the org |
| agentforce_describe_agent | Get full configuration of a specific agent |
| agentforce_list_topics | List topics for a specific agent |
| agentforce_list_actions | List actions for a specific topic |

## Examples
- "What agents do I have in this org?"
- "Show me the topics for my Service Agent"
- "What actions are available on the Billing topic?"
- "Describe the configuration of my Sales Agent"
